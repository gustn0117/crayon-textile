# 크레용 텍스타일 사이트 리디자인 — 설계

날짜: 2026-08-07

## 배경

첫 배포본은 크림 배경 + 자주/골드 포인트의 크래프티한 원페이지 구성이었다. 사용자 피드백: 디자인이 별로다, 원페이지 말고 다중 페이지, 포인트 색도 별로다, 모던하고 미니멀하게.

확정된 방향: **5페이지 / 무채색 온리 / 스위스 그리드.**

## 주제와 관객

크레용은 서울 동대문종합시장 2621호에서 30년간 나염 원단을 개발·공급해 온 텍스타일 회사다. 관객은 원단을 찾는 의류 브랜드·바이어·도매상. 사이트의 역할은 카탈로그가 아니라 **상담 유도**다. 실제 재고 데이터가 없으므로 모든 패턴 이미지는 콘셉트임을 명시한다.

## 디자인 토큰

### 컬러 — 무채색 온리

```
--paper       #FFFFFF   기본 배경
--surface     #F2F2EF   교차 섹션 배경
--ink         #0B0B0B   헤드라인, 반전 블록 배경
--body        #4F4F4B   본문
--muted       #9A9A93   라벨, 캡션
--line        #E3E3DF   1px 헤어라인
--line-strong #C7C7C1   강조 구분선
```

색으로 위계를 만들 수 없으므로 **굵기 · 크기 · 여백 · 반전 블록**이 그 역할을 대신한다. 색은 원단 사진에만 남는다.

### 타이포 — 두 개의 목소리

| 역할 | 서체 | 근거 |
|---|---|---|
| 국문 헤드라인 · 본문 | Gothic A1 (300–900) | 기하학적 한글 그로테스크. Noto/Pretendard 기본값을 피하면서 스위스 그리드와 맞는다. |
| 영문 · 코드 · 스펙 · 라벨 | IBM Plex Mono (400/500) | 텍스타일은 스펙의 산업이다 — 디자인 코드, 리피트 치수, 도수. 모노는 스펙 시트의 목소리다. |

**감수한 리스크:** 라틴 문자를 전부 모노스페이스로 간다. 히어로의 영문 아이브로우부터 대형 섹션 라벨까지 모두 모노다. 마케팅 페이지에서 잘 하지 않는 선택이지만, 무채색과 결합하면 사이트가 광고물이 아니라 **텍스타일 아카이브 색인**처럼 읽힌다. 그것이 이 회사의 실체에 더 가깝다.

### 그리드

12컬럼 · max-width 1440 · gutter `clamp(20px, 4.4vw, 72px)`.

전 페이지에 하나의 규칙을 일관되게 적용한다 — **좌측 3컬럼은 메타(영문 라벨), 우측 9컬럼은 콘텐츠.** 900px 이하에서 메타가 콘텐츠 위로 쌓인다.

### 시그니처 — 리피트 유닛

텍스타일 디자인의 핵심 단위는 **패턴 리피트**: 이음매 없이 반복되는 최소 타일. 스위스 그리드도 타일 시스템이다. 이 우연한 일치를 사이트의 시그니처로 쓴다.

컬렉션 페이지의 스와치 4종은 CSS로 그린 그레이스케일 패턴이고, hover/focus 시 **리피트 유닛 하나를 점선으로 표시**한다. 패턴이 어떻게 반복되는지를 드러내는, 이 업의 언어로 된 장치다. 화려함은 여기 한 곳에만 쓰고 나머지는 조용히 둔다.

## 넘버링 규칙

`01 / 02 / 03` 마커는 **순서가 실제 정보를 담을 때만** 쓴다.

- 페이지 5개 — 순서 없음 → 넘버링 없이 영문 라벨만
- 컬렉션 4종 — 순서 없음 → 실제 텍스타일 업계 방식대로 디자인 코드(`CR—W01`)
- 스튜디오 작업 과정 — 순서 있음 → `01`–`04` 유지

## 페이지 구성

| 경로 | 내용 |
|---|---|
| `/` | 히어로 · 지표 4종 · 하위 4개 페이지 인덱스 · 상담 CTA |
| `/about` | 회사 소개 · 인용 · 일하는 방식 3원칙 · 회사 정보 테이블 |
| `/collection` | 여성복 / 아동복 / 캐주얼 / 홈패브릭 4개 스와치 |
| `/studio` | 자체 디자인실 · 작업 과정 4단계 · 글로벌 공급 |
| `/contact` | 전화·이메일 · 주소 · 문의 시 알려주실 정보 |

홈은 요약과 유도만 담당한다. 홈에 전부 반복하면 하위 페이지가 존재할 이유가 없다.

## 파일 구조

```
src/
  app/
    layout.tsx              폰트 · 헤더 · 푸터 · 메타데이터 기본값
    globals.css             토큰 · 리셋 · 공통 프리미티브
    page.tsx | page.module.css
    about/page.tsx | about.module.css
    collection/page.tsx | collection.module.css
    studio/page.tsx | studio.module.css
    contact/page.tsx | contact.module.css
    sitemap.ts              5개 경로
    robots.ts               유지
  components/
    SiteHeader.tsx          현재 경로 강조, 모바일 패널
    SiteFooter.tsx
    PageIntro.tsx           하위 페이지 공통 상단
    Reveal.tsx              유지, 모션 절제
  lib/
    site.ts                 연락처 · 네비게이션 상수
```

기존 2,434줄 단일 `globals.css`는 폐기한다. 페이지가 5개로 늘면 관리가 불가능하다. 전역에는 토큰·리셋·프리미티브만 남기고 페이지 고유 스타일은 CSS Module로 격리한다.
